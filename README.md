# GB Wars Speed Patch

初代『GBウォーズ』（日本版）のCPU手番を短縮する非公式IPSパッチです。

CPUの行動選択、生産する兵種と場所、移動範囲の判定を維持したまま、探索と生産評価の反復処理、確定済みCPU行動の進行間隔を整理しています。ゲーム固有の演出や戦闘ルーチンを大きく置き換える方式ではありません。

## 配布物

`patches/gbwars-speed-patch.ips` が最終パッチです。`patches/gbwars-frontier-blocks.ips` は再ビルドに使う構成要素です。

対象ROMは日本版『GBウォーズ』です。配布物にはROM、セーブデータ、逆アセンブル結果、ゲーム内の画像・音声を含めていません。

| 対象 | SHA-256 |
| --- | --- |
| 未改造ROM | `a0c1e04808c7a3bf8eb306a74af333bf7a2258bae511b385ab103a5a2699bb30` |
| IPS | `d6b7403475f3e8c7d322e3d3e8301215addbbe08e9ed829e22447d67d3ba8ab5` |
| IPS適用後ROM | `c68702e791b9019c4070f8187f7b2f44fa9bccdfc3ccc8c30ca4328d6f9ec77f` |

## 適用方法

自分で所有・吸い出した対象ROMに、[Floating IPS](https://www.romhacking.net/utilities/1040/) などのIPS対応ツールで `patches/gbwars-speed-patch.ips` を適用します。作業前にROMを複製しておくと戻しやすくなります。

## 変更内容

- 移動範囲の候補管理を、コスト表全走査の負担が少ない方式に変更
- CPUの生産評価で繰り返していた34バイト表のコピーを削減
- 通常マップ上で確定したCPU行動の進行を8フレーム刻みから4フレーム刻みに変更

同じテスト局面で、行動・移動コスト表・生産判断・手番終了時の盤面を比較しました。CPU手番は、適用前の比較版からスロット1〜3で191〜196 VBlank短縮しました。生産直前からの短い局面では343から259 VBlankでした。

## 確認済みの範囲

- 通常マップのCPU手番、移動、攻撃、生産
- 既存セーブデータの読み込み
- ナウマンショトウのセーブデータ
- ホワイトムーンの最終兵器イベント

戦闘に入る時刻は変わるため、音や画面演出の長さは局面により少し変動します。テスト環境ではCPUの行動と盤面は一致しました。すべてのマップ・イベント・実機環境を網羅した検証ではありません。

## 開発資料

`scripts/build_release.py PATH_TO_GBWARS.GB` で、対象ROMと構成要素から公開版と同じ最終IPSを再生成できます。`scripts/verify_patch.py PATH_TO_GBWARS.GB` は公開IPSの対象ROMと適用後ハッシュを検証します。

`VerifyPrefixPatch.java` と `VerifyProductionTable.java` は、生産評価の直接参照化を検証した自作テストです。Emulicious.jar をクラスパスに追加して実行できます。`TraceCpuProduction.java` はセーブステートを再生してCPU生産段階を記録する補助ツールです。
